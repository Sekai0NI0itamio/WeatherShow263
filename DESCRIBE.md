# Weather Show — Modrinth draft

**Title:** Weather Show
**Description:** Replies with current weather and time remaining.
**Command:** `/weathershow`

## Body

Replies with current weather and time remaining.

### Usage

`/weathershow` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/weathershow` in chat
